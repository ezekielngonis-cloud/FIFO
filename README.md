# Ezekiel Muswere — Professional Portfolio

## Project structure
- `index.html` — page content and structure
- `css/style.css` — styling, responsive layout, and print styles
- `js/script.js` — current-year display and print-to-PDF button

## Run locally
Keep the folder structure intact, then open `index.html` in a browser.

## Update
- Edit text and project details in `index.html`.
- Change colours, spacing, and layout in `css/style.css`.
- Add interactions in `js/script.js`.

The CV's print button opens the browser print dialog. Choose “Save as PDF” to create a PDF copy.
